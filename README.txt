EUMSEONG BUS RADAR — STANDALONE PACKAGE
======================================

Isi paket:
- index.html      : Aplikasi utama jadwal & peta bus (대소·성본·무극·진천)
- manifest.json   : Konfigurasi aplikasi standalone (ikon PNG 192x192 & 512x512)
- sw.js           : Service worker cache agar bisa dibuka offline setelah dimuat
- icon-192.png    : Ikon aplikasi 192x192
- icon-512.png    : Ikon aplikasi 512x512

Cara pakai:
1. Ekstrak file ZIP ini ke folder proyek atau upload semua isinya ke root repositori GitHub Pages (https://...).
2. Buka alamat HTTPS-nya di browser Chrome di HP.
3. Pilih "Instal aplikasi" / "Add to Home screen" agar berjalan sebagai aplikasi standalone.
